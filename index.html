  1. Lead Software Engineer, OptimaAI

    Accumn, a Yubi company, Bangalore. April 2024 to now

    • Lead a team of 6 engineers that owns OptimaAI end to end, an AI credit-underwriting platform live with 10 lenders across India and MENA. Own architecture, delivery and weekly releases with product, credit and operations teams.
    • Architected a Python/FastAPI monorepo of 5 MCP servers exposing 30+ financial tools to Claude agents, so new tools or regions plug in without changing agent code.
    • Chose Temporal for taskbook execution, RFP orchestration and operations automation. Durable state and automatic retries let jobs survive failures, scaling to 100+ concurrent workflows.
    • Designed an end-to-end citation pipeline: MCP tools return cited data, LLM output is limited to citation markers, and the UI links each marker to a source panel. Credit teams get the audit trail lending decisions require.
    • Lead AI-driven Credit Assessment Memo generation. An editing agent with per-turn versioning, audit history and rollback produces a review-ready CAM in under an hour.
    • Built across the stack: async PostgreSQL, SQLAlchemy 2.0, Redis and Qdrant; OAuth/JWT with hierarchical RBAC for 6 personas; React 18 + TypeScript modules for search, AI chat, analytics and PDF export.
    • Own release and infrastructure (Docker, Kubernetes/Helm, ArgoCD, Jenkins, separate India and UAE environments), shipping weekly at 99.9%+ uptime. Set testing and review standards, mentor the team and interview candidates.
